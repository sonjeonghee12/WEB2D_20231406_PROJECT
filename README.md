# WEB2D_20231406_PROJECT

Unity 2D 프로젝트입니다.

## 프로젝트 개요
- 2D 게임 프로젝트 개발 실습용 저장소
- Unity 엔진 기반으로 제작
- 게임 로직, 씬 구성, 오브젝트 제어 등을 학습 및 구현

## 개발 환경
- Unity
- C#
- GitHub

## 실행 방법
1. Unity Hub에서 이 프로젝트를 열기
2. 해당 씬을 로드
3. Play 버튼을 눌러 실행
